## Project overview

This repository is a text-only project showcase for an enterprise resource planning (ERP) system being developed for a manufacturing business in 2026. The project is currently in progress.

At a general level, the project addresses the need to bring core operational information together in one system and support more consistent day-to-day planning and follow-up. Its high-level scope includes organising operational records, coordinating work across business functions, and providing an overview of activities to support manufacturing operations.

This page records the existence and general nature of the project only. It does not contain the project's source code, screenshots, client data, or confidential implementation details.

## Why the code is not published

The source code is not published in this repository or elsewhere in public.

The delivered code belongs to the client and is confidential. Publication or reuse of that code is prohibited. The code is kept only in an internal archive, where its integrity is recorded with a SHA-256 hash.
